I03 - SMALLEST BITS

Points: 10
Category: Intermediate / Steganography (LSB)

Scenario
An innocent-looking PNG image was transferred across a restricted boundary. Forensic analysts suspect that information has been secretly embedded into the subtle color values of the pixels.

Objective
Inspect the least significant bits of the image channels to reconstruct the hidden text and extract the flag.

Execution Reference
To run Python files: python filename.py
To compile and run C files: gcc filename.c -o output && ./output
