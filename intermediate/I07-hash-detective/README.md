I07 - HASH DETECTIVE

Points: 10
Category: Intermediate / Cryptography & Hashing

Scenario
During a forensic triage of a breached server, an investigator extracted an unsalted cryptographic password hash from an exposed database dump.

Objective
Identify the cryptographic hashing algorithm, cross-reference the hash against the provided dictionary wordlist, and recover the plaintext flag.

Execution Reference
To run Python files: python filename.py
To compile and run C files: gcc filename.c -o output && ./output
