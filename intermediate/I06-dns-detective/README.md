I06 - DNS DETECTIVE

Points: 10
Category: Intermediate / Threat Hunting & DNS Logs

Scenario
Security analysts collected network DNS query logs from a workstation exhibiting erratic behavior. An advanced persistent threat actor frequently uses domain generation algorithms and suspicious command-and-control domains to establish callbacks.

Objective
Investigate the DNS resolution log to identify anomalous high-entropy domain queries and determine the attacker's C2 domain.

Execution Reference
To run Python files: python filename.py
To compile and run C files: gcc filename.c -o output && ./output
