I05 - COOKIE TROUBLE

Points: 10
Category: Intermediate / Web Security & Cookies

Scenario
An internal company administrative dashboard manages authenticated sessions using client-side HTTP cookies. The authorization logic trusts parameters stored directly inside the user's browser cookie.

Objective
Analyze the structure and encoding of the authentication cookie, modify your user privileges to administrator, and capture the flag.

Execution Reference
To run Python files: python filename.py
To compile and run C files: gcc filename.c -o output && ./output
