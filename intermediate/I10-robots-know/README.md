I10 - ROBOTS KNOW

Points: 10
Category: Intermediate / Web Reconnaissance

Scenario
A website administrator published crawler directives to instruct search engine robots on which paths to avoid indexing. In doing so, they inadvertently created a directory of sensitive locations.

Objective
Investigate the search engine rules and discover the restricted web path to find the flag.

Execution Reference
To run Python files: python filename.py
To compile and run C files: gcc filename.c -o output && ./output
