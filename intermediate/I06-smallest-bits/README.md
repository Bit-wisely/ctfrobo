I06 - SMALLEST BITS

Points: 10
Category: Intermediate / LSB Steganography

Scenario
An operative transmitted an innocent-looking graphic across the wire, but threat intelligence suspects a hidden payload concealed within the pixel data.

Objective
Analyze the least significant bits of the image color channels using the provided extraction script to reconstruct the flag.

Execution Reference
