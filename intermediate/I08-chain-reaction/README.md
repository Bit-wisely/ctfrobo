I08 - CHAIN REACTION

Points: 10
Category: Intermediate / Multi-Stage Forensics

Scenario
An adversary packaged sensitive intelligence inside a multi-layered obfuscation wrapper designed to impede automated forensic tools.

Objective
Deconstruct each successive layer of the mystery container, reversing the encoding mechanisms stage-by-stage to reconstruct the final secret.

Execution Reference
To run Python files: python filename.py
To compile and run C files: gcc filename.c -o output && ./output
