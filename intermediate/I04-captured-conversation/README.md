I04 - THE CAPTURED CONVERSATION

Points: 10
Category: Intermediate / Network Traffic Analysis

Scenario
A network sensor intercepted unencrypted communication traffic between a client and a remote server. Sensitive transaction details and endpoint parameters were transmitted in cleartext within an isolated HTTP session.

Objective
Perform a focused packet analysis of the captured stream to identify exposed parameters and extract the cleartext secret token.

Execution Reference
To run Python files: python filename.py
To compile and run C files: gcc filename.c -o output && ./output
