I13 - HASH DETECTIVE

Points: 10
Category: Intermediate / Cryptography & Hashes

Scenario
A credential digest was recovered during an incident response investigation. Cryptographic hash functions are one-way, but weak passwords can be identified through dictionary comparisons.

Objective
Perform a dictionary attack using the provided wordlist to identify the plaintext password and construct the flag.
