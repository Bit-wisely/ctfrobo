**B03 - THE LAST ONE OUT**

**Points**: 100  
**Category**: Beginner / Data Structures  

**Challenge Overview**  
A Stack is an essential data structure in computer science that adheres to the Last-In, First-Out (LIFO) discipline. When elements are pushed onto the stack, the most recent element sits on top; when a pop operation is triggered, that newest element is removed first. In this challenge, an automated locker logs push and pop operations with ASCII numbers.

**Participant Question**  
Five things entered the locker. Some came back out. But the locker has a strange rule: The last thing put in is always the first thing removed. Follow what happens inside the locker and find what was recovered.

**Clue**  
Track the items pushed into the stack. Convert their decimal values into letters to discover the name of a hidden file in your challenge directory.
