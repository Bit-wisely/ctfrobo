B03 - THE LAST ONE OUT

Points: 5
Category: Beginner / Data Structures

Scenario
A digital security locker records push and pop operations using a Last-In, First-Out (LIFO) stack discipline.

Objective
Track the sequence of items processed by the stack and convert their decimal values to determine the hidden flag.

Execution Reference
To run Python files: python filename.py
To compile and run C files: gcc filename.c -o output && ./output
