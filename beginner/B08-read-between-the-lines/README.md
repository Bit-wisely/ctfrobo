B08 - READ BETWEEN THE LINES

Points: 5
Category: Linux / Text Investigation

Scenario
Something happened on this machine. A log file was recovered, but it contains hundreds of ordinary system entries. Somewhere inside is a message that shouldn't be there.

Objective
Search through the log file to locate the suspicious message and retrieve the answer.

Execution Reference
To run Python files: python filename.py
To compile and run C files: gcc filename.c -o output && ./output
