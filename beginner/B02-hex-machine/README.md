**B02 - HEX MACHINE**

**Points**: 100  
**Category**: Beginner / Hexadecimal  

**Challenge Overview**  
Hexadecimal (base-16) is widely used across cybersecurity and software debugging to represent raw bytes compactly. Instead of reading 8 binary bits per byte, hexadecimal uses exactly two characters (0-9 and a-f) to represent values between 0 and 255. In this challenge, the machine outputs a stream of hexadecimal bytes.

**Participant Question**  
The machine has learned a new language. It is shorter than the last one. Run it and figure out what it is trying to tell you.

**Clue**  
Two symbols represent one byte. Each pair of characters corresponds to one character in ASCII text.
