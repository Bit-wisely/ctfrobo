B09 - FIND THE PROCESS

Points: 5
Category: Linux Administration / Process Management

Scenario
A system administrator captured a snapshot of all active processes before leaving the terminal. Most entries represent legitimate system daemons or normal user applications, but one rogue process was launched from an unusual location.

Objective
Inspect the process table to identify the rogue process started from the user shell and submit its Process ID (PID).

Execution Reference
To run Python files: python filename.py
To compile and run C files: gcc filename.c -o output && ./output
