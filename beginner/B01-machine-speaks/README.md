B01 - THE MACHINE SPEAKS

Points: 5
Category: Beginner / Binary Encoding

Scenario
A legacy terminal is transmitting raw electrical pulses across the network. The stream consists entirely of zeroes and ones, encoding a hidden transmission in standard 8-bit bytes.

Objective
Decode the binary stream into ASCII text to reveal the hidden flag.

Execution Reference
To run Python files: python filename.py
To compile and run C files: gcc filename.c -o output && ./output
