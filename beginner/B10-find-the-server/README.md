B10 - FIND THE SERVER

Points: 5  
Category: Beginner / Network Identification  

Challenge Overview  
Computer networks rely on IP addressing and subnetting to route traffic between segmented internal environments. Correlating hostname records with network interfaces enables security analysts to map an organization's network topology.

Participant Question  
Four machines are connected. One is the server you're looking for. The clues contain everything you need. Find its address.

Clue  
Read `clues.txt` to identify the target hostname and subnet, then look up its IP address in `network.txt`. Format the result with underscores.

Challenge Files  
- `challenge/network.txt`
- `challenge/clues.txt`

Flag Format  
`flag{ip_<IP_ADDRESS_WITH_UNDERSCORES>}`
