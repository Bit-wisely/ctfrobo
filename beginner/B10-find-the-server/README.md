B10 - FIND THE SERVER

Points: 5
Category: Beginner / Network Identification

Scenario
Network configuration logs list various interconnected subnets and machine hostnames.

Objective
Correlate the clues with the network routing table to discover the server IP address and submit the flag.

Execution Reference
To run Python files: python filename.py
To compile and run C files: gcc filename.c -o output && ./output
