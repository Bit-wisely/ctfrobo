B03 - BASE64 ISN'T ENCRYPTION

Points: 5
Category: Encodings / Base64

Scenario
A developer claimed to have securely encrypted a secret password before sending it across the network. However, the message consists of standard alphanumeric characters and padding rather than cryptographic ciphertext.

Objective
Analyze the provided encoded message and use the decoding utility or command-line tools to recover the flag.

Execution Reference
To run Python files: python filename.py
To compile and run C files: gcc filename.c -o output && ./output
