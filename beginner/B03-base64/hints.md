Hints: B03 - BASE64 ISN'T ENCRYPTION

1. Base64 is an encoding scheme used to represent binary data in an ASCII string format, not a cryptographic encryption algorithm.
2. Look for telltale signs like characters A-Z, a-z, 0-9, and `=` padding at the end of the string.
3. Use the provided Python utility or standard Linux command line tools (`base64 -d`) to decode the string.
