B06 - THE LOST FILE

Points: 5
Category: Linux / Filesystem

Scenario
Someone left behind a directory full of old files, backups, unfinished projects, and random notes. Somewhere inside it is a file containing the information you need. You don't know where the file is located.

Objective
Navigate the filesystem to locate the target file and retrieve the answer contained inside it.

Execution Reference
To run Python files: python filename.py
To compile and run C files: gcc filename.c -o output && ./output
