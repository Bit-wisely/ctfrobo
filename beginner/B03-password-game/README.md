B03 - THE PASSWORD GAME

Points: 5
Category: Logic / Pattern Recognition / Hexadecimal

Scenario
The computer has locked the door.

The previous owner left some clues:

12       -> 2
1234     -> 4
987      -> 3
111111   -> 6

What should this be?

54321 -> ?

Objective
Run the program, deduce the password pattern to open the door, and decode what was left behind.

Execution Reference
To run Python files: python filename.py
