# Hints: B04 - HIDDEN IN PLAIN SIGHT

### Hint 1
When you browse or list the contents of a directory, default operating system behavior frequently filters out certain configuration items to keep folder views clean.

### Hint 2
In Unix-based operating systems, any file or directory whose name starts with a period (`.`) is treated as a hidden system entry.

### Hint 3
Explore the option flags available for the standard file listing utility to ensure every entry—including hidden files and directories—is rendered in the terminal.
