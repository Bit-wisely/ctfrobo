B13 - THE INBOX TRAP

Points: 5
Category: Phishing / Email Forensics

Scenario
A compromised workstation was found containing an exported email dump. The dump contains dozens of messages from different users, services, newsletters, notifications, and security systems. Many of the messages look suspicious, but somewhere in the dump is the specific email the attacker used to target the victim.

Objective
Search through the email dump and identify the phishing email. Once you find it, investigate the message and recover the hidden answer.

Execution Reference
To run Python files: python filename.py
To compile and run C files: gcc filename.c -o output && ./output
