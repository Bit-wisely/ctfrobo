B07 - HIDDEN IN PLAIN SIGHT

Points: 5
Category: Linux / Filesystem

Scenario
Someone searched through this directory and claimed there was nothing useful here. Maybe they didn't look carefully enough.

Objective
Find what has been hidden inside the provided directory and retrieve the answer from the file inside it.

Execution Reference
To run Python files: python filename.py
To compile and run C files: gcc filename.c -o output && ./output
