B07 - THE SEARCHER

Points: 5
Category: Beginner / Algorithms

Scenario
A binary search algorithm navigates a sorted array of numbers by repeatedly halving the search window to locate target 1131.

Objective
Count the exact number of midpoint comparison steps required to find the target and submit the flag.
