# A01 - THE BINARY SECRET

Points: 20
Category: Advanced / Reverse Engineering

## Scenario
A compiled mystery program protects a confidential secret by obfuscating its internal comparison checks. The binary refuses to reveal the passphrase through plain text inspection.

## Objective
Analyze the binary logic and reverse the transformation algorithm to recover the hidden flag.

Execution Reference
To run Python files: python filename.py
To compile and run C files: gcc filename.c -o output && ./output
